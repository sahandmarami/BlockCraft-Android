# بلاک کرَفت — BlockCraft v3.0.0 🎮⛏️

بازی وکسلی ساندباکس به سبک ماینکرافت — کاملاً فارسی، کاملاً رویه‌ای (بدون هیچ فایل گرافیکی آماده)، مخصوص اندروید و مرورگر.

**دانلود APK:** از بخش [Releases](../../releases) → `BlockCraft-v3.0.0.apk`

---

## تازه‌های نسخه ۳

- 🎮 **کنترل ماینکرافتی:** دی‌پد ۸جهته پایین-چپ (مثل ماینکرافت پاکت‌ادیشن) — گوشه‌ها حرکت مورب می‌دهند، دو ضربه سریع روی ▲ = دویدن
- 🧱 **مکانیزم بلوک:** هر بلوکی که می‌شکنی مال توست! چمن → خاک، سنگ → سنگ‌فرش. با گذاشتن، یکی از مقادیر کم می‌شود (استک ۶۴تایی مثل بازی اصلی)
- 🐑 **حیوانات بیشتر:** گوسفند، گاو، خوک و مرغ (تا ۱۴ عدد همزمان) + زامبی‌های شبانه (تا ۶ عدد) که صبح می‌سوزند
- ✋ **دست خالی:** وقتی بلوکی در دست نداری، بازوی شخصیت مثل بازی اصلی دیده می‌شود
- 🌄 **گرافیک بهتر:** لبه چمن روی خاک، آب پررنگ‌تر با موج، برگ‌های انبوه‌تر، مه هم‌رنگ آسمان، شب واقعاً تاریک با ستاره‌ها

## امکانات کلی

- دنیای بی‌پایان رویه‌ای: دشت، جنگل، بیابان، برف + غار و کانه‌ها (زغال/آهن/طلا/الماس)
- حالت **بقا**: جان ۱۰قلبی، گرسنگی، خفگی زیر آب، صدمه سقوط، خواب در تخت تا صبح، نقطه تولد دوباره
- حالت **خلاقانه**: پرواز، بی‌مرگی، صندوق همه بلوک‌ها
- صدا و موسیقی کاملاً سنتزشده (WebAudio): قدم، کندن، جانورها، جیرجیرک شب، آواز پرنده‌ها
- ذخیره خودکار دنیا + مقادیر؛ بدون نیاز به اینترنت
- همه گرافیک و صداها در لحظه تولید می‌شوند — هیچ دارایی آماده‌ای وجود ندارد

## نصب روی اندروید

1. **نسخه قبلی را حذف (Uninstall) کنید** — امضای v3.0.0 جدید است و روی نسخه قبلی نصب نمی‌شود.
2. `BlockCraft-v3.0.0.apk` را از Releases دانلود و نصب کنید (اجازه نصب از منابع ناشناس).
3. بازی کاملاً آفلاین اجرا می‌شود.

> حداقل اندروید ۷.۰ (API 24) — روی گوشی‌های ضعیف فاصله دید را در تنظیمات کم کنید.

## اجرای نسخه وب

```bash
bun install
bun dev        # http://localhost:3000
```

## ساخت APK از سورس

```bash
STATIC_EXPORT=1 bunx next build          # خروجی استاتیک → out/
scripts/build-apk.sh                     # WebView wrapper + امضا (به SDK اندروید نیاز دارد)
```

## ساختار پروژه

```
src/lib/game/    موتور بازی (WebGL/Three.js): chunks, mesher, AO, فیزیک، ماب‌ها، آسمان، صدا
src/components/game/VoxelGame.tsx   رابط فارسی: منو، دی‌پد، hotbar، تنظیمات
android/         پوسته اندروید (WebView آفلاین + آیکون‌ها)
scripts/         ساخت APK و آیکون‌ها
```
